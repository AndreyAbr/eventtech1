# EventTech Hub — Единая платформа управления мероприятиями (MVP Хакатона)

Разработать полнофункциональное клиентское веб-приложение (SPA) для организации, координации и проведения мероприятий любого масштаба. Приложение должно обеспечивать полный цикл управления ивентом в едином цифровом пространстве: от создания паспорта события и распределения задач (Kanban/Список) до контроля бюджета, ведения базы подрядчиков, регистрации участников с генерацией QR-билетов, чек-ина и встроенного ИИ-ассистента организатора. Прототип должен запускаться мгновенно с предзаполненными демонстрационными данными без необходимости настройки внешнего бэкенда.

---

## 1. Tech Stack & Environment

* **Runtime & Bundler**: Node.js (v18+), Vite (`^5.0.0`), TypeScript (`^5.3.0`).
* **UI Framework**: React (`^18.2.0`), React DOM (`^18.2.0`).
* **Styling**: Tailwind CSS (`^3.4.0`), PostCSS, Autoprefixer, `clsx`, `tailwind-merge`.
* **Icons**: `lucide-react` (`^0.360.0`).
* **QR Code Generation**: `qrcode.react` (`^3.1.0`) — генерация индивидуальных SVG QR-кодов для участников.
* **State & Persistence**: React Context API + `localStorage` синхронизация (ключ `eventtech_store_v1`) с функцией сброса к эталонным демо-данным (`resetToSeedData`). Никаких внешних стейт-менеджеров (Redux, MobX, Zustand).
* **Export Utilities**: Нативный браузерный `Blob` API для выгрузки списков участников и финансовых отчетов в формате CSV (UTF-8 с BOM `\uFEFF` для корректного открытия кириллицы в Excel).

Phase 3: Бизнес-логика, аналитика и ИИ-генератор (src/utils/)

    src/utils/analytics.ts:

        Функция calculateEventMetrics(event, tasks, budget, guests):

            readinessPercent: процент выполненных задач (status === 'done') от общего числа задач мероприятия (0–100%).

            overdueTasksCount: количество задач, у которых new Date(task.deadline) < new Date(today) и task.status !== 'done'.

            totalPlannedBudget: сумма plannedAmount всех статей расходов.

            totalActualBudget: сумма actualAmount всех статей расходов.

            isOverTotalLimit: булево значение (totalActualBudget > event.totalBudgetLimit или totalActualBudget > totalPlannedBudget).

            registeredCount: число гостей со статусом !== 'cancelled'.

            checkedInCount: число гостей со статусом === 'checked_in'.

            attendanceRate: процент пришедших (checkedInCount / registeredCount * 100).

            costPerAttendee: стоимость привлечения/обслуживания одного участника (totalActualBudget / Math.max(1, registeredCount)).

    src/utils/csvExport.ts:

        Функция exportGuestsToCSV(guests: GuestItem[], eventTitle: string): формирует CSV-строку с колонками ID,ФИО,Email,Телефон,Организация,Тип билета,Статус,QR-токен,Дата регистрации, добавляет префикс \uFEFF и инициирует скачивание файла.

        Функция exportBudgetToCSV(budget: BudgetItem[], eventTitle: string): аналогичная выгрузка финансового отчета.

    src/utils/aiGenerator.ts:

        Детерминированный интеллектуальный движок generateEventBlueprint(event: EventEntity, currentTasks: TaskItem[], currentBudget: BudgetItem[]), который на основе типа мероприятия (EventType), планового числа гостей и общего лимита бюджета:

            Генерирует рекомендуемый чек-лист задач с реалистичными сроками относительно даты старта мероприятия.

            Рассчитывает оптимальное процентное распределение бюджета по категориям (например: Кейтеринг 30%, Площадка 25%, Оборудование 20%, Маркетинг 15%, Мерч 10%) с конкретными суммами в рублях.

            Выявляет потенциальные риски проекта (например, дефицит бюджета, просроченные критические задачи, низкий процент регистраций менее 50% от плана, отсутствие назначенных подрядчиков по технике) и выдает рекомендации по их устранению.

            Генерирует почасовую программу (тайминг) мероприятия.

            Позволяет в 1 клик применить сгенерированные задачи и статьи бюджета прямо в активное мероприятие.

5. Edge Cases & Error Handling

    Защита от деления на ноль в аналитике: если у мероприятия 0 задач или 0 зарегистрированных гостей, все метрики (readinessPercent, attendanceRate, costPerAttendee) должны корректно возвращать 0 без появления NaN или Infinity в интерфейсе.

    Валидация форм:

        Запретить создание мероприятия, задачи, статьи расхода или гостя с пустым названием/ФИО.

## 2. Исправление верстки и форматирования в смете (`src/components/views/BudgetView.tsx`)

Устранить 4 дефекта таблицы расходов:

1. **Убрать артефакт `"-0 ₽"` в расчете отклонений**:
   * Написать чистую хелпер-функцию `formatVariance(actual: number, planned: number)` для строк и для строки `ИТОГО`:
     * Пусть `const diff = actual - planned;`.
     * Если `diff === 0`: возвращать строго `'0 ₽'` с классом `text-zinc-400` (без знака `-` или `+`).
     * Если `diff > 0` (перерасход): возвращать `'+' + diff.toLocaleString('ru-RU') + ' ₽'` с классом `text-red-600 font-medium`.
     * Если `diff < 0` (экономия): возвращать `'−' + Math.abs(diff).toLocaleString('ru-RU') + ' ₽'` с классом `text-emerald-600`.
2. **Исправить разорванные бейджи категорий (`Маркетинг и реклама`)**:
   * В первом столбце таблицы обернуть название категории в `span` со строгим запретом переноса строк:
     `inline-flex items-center whitespace-nowrap px-2 py-0.5 rounded text-xs font-medium bg-zinc-100 text-zinc-700 border border-zinc-200/80`.
3. **Форматирование и правое выравнивание инпутов «ФАКТ, ₽»**:
   * В ячейке `ФАКТ, ₽` прижать контейнер к правому краю (`text-right`).
   * Внутри инпута выровнять цифры по правому краю (`text-right font-mono tabular-nums pr-6`) и добавить справа внутри обертки (`relative inline-flex items-center`) приглушенный символ `₽` (`absolute right-2 text-xs text-zinc-400 pointer-events-none font-mono`), чтобы числа в инпутах читались единообразно с колонкой `ПЛАН, ₽`.
4. **Пропорции колонок и выравнивание подвала `<tfoot>` (`ИТОГО`)**:
   * Строка `ИТОГО` обязательно должна быть сверстана через `<tfoot><tr className="bg-zinc-50/90 border-t border-zinc-200 font-semibold">...</tr></tfoot>` внутри того же элемента `<table>`, с точно таким же количеством ячеек `<td>` и теми же классами `px-3.5 py-2.5 text-right font-mono tabular-nums whitespace-nowrap`, чтобы итоговые суммы стояли строго под своими колонками `ПЛАН, ₽`, `ФАКТ, ₽` и `ОТКЛОНЕНИЕ`.
   * Задать колонке «Статья расходов» класс `max-w-[260px]`, а колонкам «Подрядчик» и «Заметки» — `min-w-[150px] max-w-[200px] truncate` с обязательным атрибутом `title={...}` для просмотра полного текста при наведении.
